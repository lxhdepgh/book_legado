# 单进程打包说明

**架构**：Flutter 前端自动拉起内置 Python 后端，用户只需双击一个 exe。

## 一键打包

```powershell
.\build_release.ps1
```

执行流程：
1. PyInstaller 打包 Python 后端 → `legodo_dart/backend/LegadoReader.exe`（21MB）
2. Flutter build windows --release（嵌入后端路径）→ `legodo_client.exe`（89KB）
3. 复制 backend 目录到输出目录

## 输出文件

```
legodo_dart\build\windows\x64\runner\Release\
├── legodo_client.exe          (89KB)   ← Flutter 前端
├── flutter_windows.dll        (21MB)   ← Flutter 引擎
├── data\                      ← Flutter 资源
└── backend\
    ├── LegadoReader.exe       (21MB)   ← PyInstaller 打包的 Python 后端
    └── _internal\             ← Python 依赖 + schema 文件
```

完整路径：
```
D:\WorkSpace\PycharmProjects\legodo_booksource_check\legodo_dart\build\windows\x64\runner\Release\legodo_client.exe
```

## 启动方式

**Release 版本**（单进程）：
```powershell
# 直接双击或命令行启动，自动拉起 Python 后端
.\legodo_dart\build\windows\x64\runner\Release\legodo_client.exe
```

**开发模式**（双进程手动启动）：
```powershell
# 终端 1：启动 Python 后端
python main.py --serve --port 8000

# 终端 2：启动 Flutter 应用
.\run_flutter.bat
```

## 工作原理

1. Flutter exe 启动时从 `Platform.resolvedExecutable` 同级目录查找 `backend\LegadoReader.exe`
2. 自动执行 `LegadoReader.exe --serve --port 0 --idle-seconds 15`
3. 读取 stdout 中的 `LEGODO_GATEWAY {...}` 握手行获取端口和令牌
4. 建立 RPC 连接并显示书架界面
5. 退出时自动终止 Python 子进程

## 关键配置

### PyInstaller spec（LegadoReader.spec）

必须收集的资源：
```python
datas=[
    ("app/resources/publicsuffixes.gz", "app/resources"),
    ("app/gateway/schema/*.json", "app/gateway/schema"),  # action 入参 schema
]
```

### Flutter 构建参数

```powershell
flutter build windows --release ^
  --dart-define=LEGODO_PYTHON=<backend_exe_path> ^
  --dart-define=LEGODO_MAIN=<main_py_path>
```

### bootstrap.dart 回退逻辑

当 `EngineProcess.start()` 失败（无 LEGODO_PYTHON/LEGODO_MAIN 环境变量）时：
- 从 `Platform.resolvedExecutable` 同级查找 `backend\LegadoReader.exe`
- 启动打包的后端 exe 并读取握手行
- 传递令牌建立 RPC 连接

## 常见问题

### Schema 文件缺失

**症状**：书源列表加载失败，提示 `action 'source.list' 没有入参 schema`

**原因**：PyInstaller spec 的 datas 未收集 `app/gateway/schema/*.json`

**修复**：添加 `("app/gateway/schema/*.json", "app/gateway/schema")` 到 LegadoReader.spec

### 令牌 401 错误

**症状**：界面显示"令牌不对：引擎回 401"

**原因**：bootstrap.dart 回退逻辑用空令牌连接外部服务

**修复**：改为启动打包的 LegadoReader.exe 并读取握手行获取令牌

### 后端进程残留

**症状**：重启应用时报端口占用

**原因**：旧后端进程未正常退出（idle-seconds 15s 超时自杀）

**修复**：手动杀掉旧进程或等待 15s 后重试

## 清理可重复生成文件

```powershell
# Python 后端构建产物
Remove-Item -Recurse -Force build/LegadoReader, dist, legodo_dart/backend

# Flutter 构建产物
cd legodo_dart
Remove-Item -Recurse -Force build, .dart_tool
```

这些文件可通过 `build_release.ps1` 重新生成，不应提交到 git。
