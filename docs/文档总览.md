## 0. 现在跑的是哪一版

**单进程 FFI**：`legodo_client.exe`（Flutter AOT）`LoadLibrary` 同目录的 `legodo_engine.dll`（Go c-shared）。
无服务进程、无网络端口、无 WebSocket、不涉及 Python。

| 面 | 数量 | 口径（当场数，2026-10-20） |
|---|---|---|
| `legodo_dart/lib/` Dart 文件 / 行 | 81 / 20,244 | `find … -name "*.dart" \| wc -l`、`wc -l` |
| 屏与对话框 | 20 | `*_screen.dart` + `*_dialog.dart` |
| `legodo_dart/test/` 测试文件 | 36 | 同口径 |
| `backend_go/` Go 文件 / 行 | 98 / 34,644 | 同口径 |
| `internal/services/` 文件 | 49 | `ls` |
| 在册服务名 | 23 | `register.go` 里 `NewBaseService("X")` 去重 |
| FFI 动作分发面 | **89**（同步 88 + 直连 1） | 仓库自有提取器 `go test ./pkg/ffi/ -run Route` 现绿，断言在 `route_test.go:141` |
| 根 `tests/` pytest 文件 / 函数 | 80 / 1547 | 面向 `legodo_flet/app/`（如 `tests/test_gateway_contract_single_source.py:31` 的 `FLET = ROOT / "legodo_flet"`） |

关键契约的落点：C 符号只有 `Initialize` / `Call` / `Cleanup` / `FreeString`
（`lib/core/ffi/engine_ffi.dart:218-221`）；事件没有推送，Dart 每 250 ms 带游标轮询
`engine_poll`（`lib/core/rpc/ffi_engine_adapter.dart:323`）；数据目录取 `%LOCALAPPDATA%`
（`backend_go/internal/services/register.go:37-40`），主库是 `legado.db`（`core/storage.go:40`）。

**两代已废**：G1 = 根 `app/` Flet 进程内多服务（M1–M7 那套）；G2 = 双进程网关（Python PyInstaller
后端 / Go 独立服务，over `ws://…:8080/rpc`）；G3 = 现主线。凡正文让你去 `app/services/*.py` 找文件、
去 `backend/LegadoReader.exe` 找产物、去 `:8080` 找端口的，指的都是不存在的东西。

## 6. 新文档的落点

要新增顶层文档，先问它能不能挂进已有的四份：现状设计 → `current-system-design.md`；
缺什么/做什么 → `dart补缺方案.md`；某功能域的行为契约 → 对齐类文档（如 `找书与换源逻辑对齐.md`）；
性能账 → `运行卡顿归因与优化方案.md`。四份都挂不下的才新开，并在本文件 §1 加一行。

写文档时的三条硬规矩（项目记忆同步）：数字必须当场测得并附口径（哪条命令、哪个文件:行）；
引用别处的数字要带出处，不许凭印象复述；**开头第一句写清它描述的是哪一代（G1/G2/G3）**——
本轮整理的 90% 起因就是三代各留了一份不标代际的设计文，而 `required: true` 恰好挑中了最旧那两份。
