# 密钥管理策略（secrets-policy）

> 状态：骨架（初始化生成于 2026-09-01），待补充处需开发者确认后补全。

## 1. 硬性规定

- **严禁**将令牌、密码、私钥、Cookie、已填充的 `.env` 值写入仓库任何文件（含 `codeConfig.yaml`、文档、日志）。
- 智能体不得在代码或文档中回填任何真实凭证。

## 3. 日志脱敏（待补充）
