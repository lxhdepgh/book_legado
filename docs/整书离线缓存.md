# 整书离线缓存

在书架书籍右侧打开“书籍管理”，选择“缓存全本”。任务会先读取或刷新目录，然后依次缓存所有非卷标题章节。

实现与 Legado `CacheBook` 的核心行为保持一致：

- 已缓存章节自动跳过，可停止后继续。
- 单章失败最多重试 3 次；完成后显示成功、总数和失败数。
- 同一本书不会同时启动两个缓存任务。
- “停止缓存”保留已经完成的章节。
- “清除缓存”停止当前任务并删除目录、正文、图片和离线标记。
- 远程图片连同请求头下载并嵌入章节缓存，支持漫画离线阅读。
- 用户主动缓存的整书不参与普通阅读缓存的容量淘汰。

缓存保存在各系统标准缓存目录的 `reader-cache` 下，路径规则见《数据与缓存目录》。切换书源或移出书架时会清理原书源对应缓存。
