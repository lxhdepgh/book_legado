# 整书离线缓存

在书架书籍右侧打开“书籍管理”，选择“缓存全本”。任务会先读取或刷新目录，然后依次缓存所有非卷标题章节。

实现与 Legado `CacheBook` 的核心行为保持一致：

- 已缓存章节自动跳过，可停止后继续。
- 单章失败最多重试 3 次；完成后显示成功、总数和失败数。
- 默认使用 4 个并发工作单元，可在服务层配置为 1—8；每个工作单元使用独立阅读引擎和 JS 状态。
- 同一本书不会同时启动两个缓存任务。
- “停止缓存”保留已经完成的章节。
- “清除缓存”停止当前任务并删除目录、正文、图片和离线标记。
- 远程图片连同请求头下载并嵌入章节缓存，支持漫画离线阅读。
- 用户主动缓存的整书不参与普通阅读缓存的容量淘汰。

并发只作用于同一本书的待缓存章节。目录解析仍先单独完成，已缓存章节不会进入任务队列；因此续传不会浪费并发请求。停止任务会同时取消全部工作单元。

缓存保存在各系统标准缓存目录的 `reader-cache` 下，路径规则见《数据与缓存目录》。切换书源或移出书架时会清理原书源对应缓存。

书架列表和网格使用四种状态区分：未缓存、部分缓存 `x/y`、已离线、缓存中。状态同时使用图标和文字，颜色取自当前主题的语义色，不依赖固定蓝色或灰色，因此适配浅色、深色、墨水屏与自定义皮肤。
