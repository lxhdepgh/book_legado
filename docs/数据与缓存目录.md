# 数据与缓存目录

应用运行时不向 EXE、安装目录或打包临时解压目录写入文件。首次启动时没有书源，列表为空；导入书源后所有修改都写入用户目录中的副本，仓库不再内置书源种子。

| 系统 | 用户数据目录 | 缓存目录 |
|---|---|---|
| Windows | `%LOCALAPPDATA%\LegadoBookSourceCheck` | `%LOCALAPPDATA%\LegadoBookSourceCheck\cache` |
| macOS | `~/Library/Application Support/LegadoBookSourceCheck` | `~/Library/Caches/LegadoBookSourceCheck` |
| Linux | `$XDG_DATA_HOME/LegadoBookSourceCheck`，缺省为 `~/.local/share/LegadoBookSourceCheck` | `$XDG_CACHE_HOME/LegadoBookSourceCheck`，缺省为 `~/.cache/LegadoBookSourceCheck` |

用户数据包括：

- `bookSource.json`：当前书源及导入结果
- `bookshelf.json`：书架和阅读进度
- `appearance.json`：外观配置
- 规则状态、Cookie 等需要跨启动保留的内容

缓存包括：

- `reader-cache/`：目录和章节正文缓存
- `edge-webview-profile/`：桌面网页验证配置

可通过 `LEGADO_BOOKSOURCE_DATA_DIR` 和 `LEGADO_BOOKSOURCE_CACHE_DIR` 覆盖两个目录，适用于便携版、测试和受管环境。旧版本位于数据目录下的阅读缓存和 Edge 配置会在首次启动时复制到新缓存目录；Linux/macOS 旧的 `~/.legado_booksource_check` 数据也会迁移到标准目录。
