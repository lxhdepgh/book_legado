## 2. BrowserService 实现要点（契约 §11 / §1.19 / §3.3）

- **收编而非重写**：无头侧直接持有 `headless_browser.BROWSER` 进程级单例（懒解析），
  profile 目录 `chromium-profile/` 登录态、`_watch_requests` 嗅探、`BLOCKED_RESOURCE_TYPES`
  拦图片等逻辑全部留在原模块；本服务只做 on_stop 统一回收（`aclose`）。
- **对外 API**：
  - `async fetch(url, options=None, **opts)` —— 无头渲染，委托 `HeadlessBrowser.fetch`；
    options 与 kwargs 合并透传（None 值不注入）。
  - `async open_interactive(url, callbacks=None, on_frame=None, options=None)` ——
    CDP 投屏，经 `interactive_factory`（默认懒加载 `InteractiveBrowser`）起会话，
    返回交互句柄（tap/scroll/type_text/capture/close），会话登记入服务会话池。
  - `async render_webview(url, source=None, options=None)` —— webView/验证码请求，
    懒构造 `WebPageRenderer` 委托；`ftw.WebView` 平台判定分支原样保留。
  - `async verification_fetcher(image, source)` —— 验证码取页，委托 renderer。
  - `available_fetcher()` —— 内核就绪返回 Legado 形状 fetcher `(url, source, options)`，
    否则返回 **None**（不报错），调用方据此退回非浏览器路径。
- **回调注册表（§4.6 唯一例外通道）**：`register_interaction_callback(cb)` /
  `set_page_provider(provider)`；视图层实现 `BrowserInteractionCallback` 注入，
  服务本身零 flet import、不持有控件。
- **降级**：`chromium_probe` 可注入；默认懒查 `chromium_installed()`（不 import playwright、
  不拉起进程）。playwright 未装时 `available_fetcher()` 返回 None；被收编模块内部的
  playwright import 全部懒加载（方法内 import）。
- **会话池/生命周期**：有头投屏会话登记在 `self._sessions`（`session_count` 可观测），
  `on_stop` 逐个 `close()` 后关无头单例。
- **依赖方向例外（§5.2）**：`dependencies=()`，协作者经 on_start/构造注入解析，
  不反向 import reading/；BrowserInteractionCallback 定义在 core，视图实现注入。

## 3. WebBridgeService 实现要点（契约 §10 / §1.15）

- **安全面**：默认绑定 `127.0.0.1`（回环，三端无平台分支，免局域网防火墙弹窗）；
  开关 `webbridge.enabled` 默认 **False**；on_start 关闭时**不监听**（SUSPENDED 语义，
  `listening=False`/`bound_port=0`）；启用后全端点经令牌校验
  （`Authorization: Bearer <token>` 或 `?token=`，不符 401）。
- **懒启动**：on_start 读开关，开则 `start_server()`，关则仅记录；并订阅
  `SettingsChangedEvent(webbridge.enabled)` 运行期热启停。
- **薄协议层（业务全委托，不重复实现）**：
  - `GET  /api/health`
  - `GET  /api/sources` → `SourceService.list_sources()`
  - `POST /api/sources` → `SourceService.save_source(json)`
  - `DELETE /api/sources/{url}` → `SourceService.delete_source(url)`
  - `POST /api/sources/check` → `SourceCheckService.check_source(body)`
  - `POST /api/sources/check_all` → `SourceCheckService.check_all(groups)`
  - `POST /api/sources/debug` → `RuleEngineService`（action=search/bookInfo/chapters/content）
  - `GET  /ws` → EventBus 调试事件（SourceChanged/CheckFinished）广播推 WebSocket
- **令牌生成**：首次启用且未配置时 `secrets.token_hex(16)` 生成并写回
  `SettingsService`（键 `webbridge.token`）。
- **红线 §5 说明**：token 是用户**显式开启网桥后**才生成的本机回环二次防护口令，
  默认关闭时不生成、不写库；非第三方凭据泄漏。生产由用户在设置页显式开启。

## 5. 与契约的偏差

- **dependencies 声明**：契约 §1 表列 WebBridgeService 依赖 SourceService/
  SourceCheckService/RuleEngineService/EventBus、BrowserService 依赖 RuleEngineService/
  EngineHub。本实现为并行四线解耦，拓扑 `dependencies=()`，协作者一律经 on_start
  懒解析（`hub.require`）或构造注入（对齐 SourceCheckService 既有模式），语义等价、
  不硬耦合未交付类。
- **SUSPENDED 状态字面**：Service 基类 on_start 成功后统一迁 RUNNING；本服务在开关
  关闭时不监听，对外可观测 `listening=False`/`bound_port=0` 体现 SUSPENDED 语义，
  未强行改写基类状态机。
- **render_webview 构造**：`WebPageRenderer` 顶部 import flet，故在本服务内**方法内
  懒加载**（仅视图层注入 page_provider 后才触碰），保证 BrowserService 模块零 flet import。
