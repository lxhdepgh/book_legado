## 2. 客户端选型裁决（契约 §3 要求写明理由）

**采用 aiohttp 自实现 PROPFIND/PUT/GET，不引入 webdavclient3。**

1. 本服务跑在主进程异步网络栈上，aiohttp 3.14 已是全项目统一 HTTP 客户端；
   webdavclient3 底层是 requests 同步库，需要 `run_in_executor` 线程池桥接，
   徒增阻塞风险与依赖；
2. 我们只用 WebDAV 三个最小动作（PROPFIND 列目录 / PUT 上传 / GET 下载，
   外加可选 MKCOL 建目录），自实现约百行、语义透明，无需为全量 WebDAV
   特性（锁/版本控/属性补丁）背重型依赖；
3. aiohttp 自实现天然复用现有超时 / UA / 代理配置，三端一致。

WebDAV 连接配置从 `SettingsService` 读 `webdav.url/username/password`；
测试直接注入实现了 `list/download/upload/mkdir` 鸭子接口的本地目录假客户端，
零网络。

## 3. WebDavService（§1.5）

- 备份编排"导出 zip → 上传"：
  - `bookSources.json` —— `SourceService.export_sources_json()` 产物（Legado 书源数组格式）；
  - `bookShelf.json` —— Legado Book 记录数组（与 bookshelf.json 磁盘格式一致）；
  - `config.json` —— 读者偏好子集（剔除 `webdav.password` 等凭据）；
  - `replaceRules.json` / `dictRules.json` / `rssSources.json` —— 可选并行线服务，
    鸭子类型探测其 `export_*_json` 方法，未注册/未交付时缺省不阻断。
- zip 内含 `meta.json`：`{format, version, exported_at, manifest:{成员: sha256}}`。
- 远端路径：`legado/backup/legado_backup_<时间戳>.zip`。
- 恢复是高风险写操作，**强制校验闸门**（`_validate_backup_zip`）：
  1. zip 可打开；2. `meta.json` 可读且 `format/version` 匹配；
  3. manifest 每个成员重新算 SHA-256 比对；4. 各 JSON 可解析。
  任一失败 → `BackupResult(ok=False)` 且**不触碰本地数据**（测试 4/5 守门）。
- 校验通过才写回：书源经 `import_sources_json`、书架整体替换后 `save_bookshelf`、
  设置逐条 `set`。
- 完成即发 `BackupFinishedEvent(kind, ok, detail)`，无论成败。

## 4. BookExportService（§1.12）

- `export_epub(book_url)` / `export_txt(book_url)`：
  - 由 `book_url` 从 `SourceService.bookshelf` 反查 `source_url` 与书元数据（离线）；
  - 章节顺序/标题读缓存 catalog（与 `ReadingService.load_chapters` 同源，离线命中不联网）；
  - 正文只读 `ReadingCache.load_content`，**未缓存章节跳过，不重新联网**；
  - 卷标题（`is_volume`/空 url）不出正文；
  - 产物落 `StorageService.download_dir()`。
- epub 用 ebooklib 组装；内联图片（已缓存 bytes）按文件头嗅探格式后内嵌为 EpubImage；
  封面仅当 `cover_url` 指向本地已存在文件时用 Pillow 归一内嵌（远端不抓）。
- txt 自写 UTF-8。

## 5. UpdateService（§1.17）

- `check_update()`：默认查 GitHub latest release API（`update.api_url` 可配 Gitee）；
  版本号 `v1.2.3`→(1,2,3) 数字元组比较；命中较当前新且未被忽略时
  发 `UpdateAvailableEvent(version, notes, url)`；无论结果都记 `update.last_check_time`。
- `download(info)`：安装包落 `downloads/`，提供 digest 时校验 sha256，不符即抛错不落盘。
- `ignore_version(version)`：记 `update.ignored_version`。
- **不做静默自替换**：检查→提示→下载到 downloads/→用户手动安装（§1.17 三端差异规避）。
- 网络入口 `http_get_json`/`http_download` 可注入，测试全程离线 stub。

## 7. 与契约偏差

1. **`restore(url, token)` 签名**：契约写 `restore(url, token)`。实现中 `url` 为远端
   备份包路径；`token` 形参保留但未用作独立凭据——WebDAV 凭据统一来自
   `SettingsService.webdav.*`，`token` 预留为一次性口令覆盖位（当前未启用）。
   属参数语义澄清，不影响调用方向。
2. **可选并行线服务（ReplaceRuleService/DictService/RssService）**：本线不硬依赖，
   经鸭子类型探测导出/导入方法，未注册时备份包缺该成员。待 Agent B 落地后，
   若其导出方法名与 `export_rules_json`/`import_rules_json` 不一致，仅需在
   `_collect_members`/`_apply_members` 的成员映射处对齐方法名。
3. **设置导出为白名单子集**：未做 settings 全量导出（避免跨端 schema 漂移），
   仅导出 `reader.*`/`theme.skin` 等已知键。M6 存储收敛后可扩充。
