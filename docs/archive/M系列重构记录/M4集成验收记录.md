## 4. 与契约偏差（M4 累计，写入各线记录）

1. **mobi/umd 登记不支持**（LocalBook）：ebooklib 不支持 mobi；umd 无成熟纯 Python 库——按"不硬凑"明确报 UnsupportedFormatError，不引入额外库。
2. **LocalBookService 依赖收敛为 ()**：本地解析不触网，正文缓存直接用 ReadingCache（契约允许"经 BookCacheService 或 ReadingCache"）。
3. **RSS 规则订阅最小兜底**：逐字段 ruleTitle/rulePubDate/ruleContent 求值留 M5；标准 feed（feedparser）是 M4 完整主路径。
4. **HttpTts 只取流不播出声**（M4 契约本就写"基础请求"）：音频流传播放器接 flet_audio 留 M5；BookCacheService 音频缓存接口已留构造参数。
5. **漫画缓存命中口径**：反映渲染通道内字节缓存命中率（M2 fetch_page_image 不返回磁盘缓存元数据），磁盘命中率待服务扩展；进度落章节级（页内滚动比例 M5 补）。
6. **RssService 不列 SettingsService 依赖**：UA/超时由 RuleEngineService 自身注入，经 on_start 软取。
