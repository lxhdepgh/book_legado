## 3. migrate() 行为（契约 §2）

- 时机：`StorageService.on_start` 在 `ensure_schema()` 之后、`_bind` 之前调用；拓扑上 StorageService 先于 SourceService 启动，故后续服务读到的已是主库数据。
- 只读导入：4 类旧介质全部位于 `AppPaths.data`。
  - `bookSource.json → book_sources`：投影 id(=bookSourceUrl)/name/url/group/enabled/custom_order/respond_time，`json` 列存原文全文；缺 `bookSourceUrl` 的条目进 `missing` 清单。
  - `bookshelf.json → bookshelf`：投影 book_url/source_url/name/author/kind/cover_url/in_bookshelf；`reading` 列存 reading 块原文（原样保留）；`vars` 列存 variables；另加 `payload` 列存整条记录全文（保留 toc_url/intro 等 Legado 别名，供继承的旧书架方法无损往返）。
  - `search-books.sqlite3 → search_books`：旧库只读连接，按行投影，从 `payload` JSON 解出 kind/origin_name；`saved_at`(ms) 原样保留作 24h TTL 锚。
  - `appearance.json → settings`：并入键 `appearance.snapshot`（与 M5 ThemeService 统一键一致）；该键已存在则不覆盖。
- 备份：导入成功的旧文件改名 `<name>.legacy-bak`（不覆盖已有备份），**不删除**；导入失败/解析异常的文件不改名、保留现场并记 `missing`。
- 幂等：settings 表写标记 `m6.legacy_migrated`；二次 `migrate()` 见标记即返回 `already_migrated=True`、计数 0，不重复导入。
- 返回迁移报告 dict：`book_sources/bookshelf/search_books/appearance` 各类条数 + `missing`（字段缺失/非法/异常清单）+ `backed_up`（已改名文件）+ `already_migrated`。报告由调用方/集成方汇入 `docs/M6迁移报告.md`。

## 4. 旧介质只读不写验证

- migrate 后 4 类旧文件均 `.legacy-bak` 且原文件消失（测试 1 断言）。
- SourceService 保存新书源后，`bookSource.json` 不再生成（测试 6 断言 `not exists`）。
- SearchBookStore 默认走主库 `search_books`，不再自建 `search-books.sqlite3`（垫片 conn 注入，测试 7）。

## 5. 读取仲裁裁决（契约 §3 要求记录）

**续读进度以 `books` 表（M2 结构化列）为唯一权威；`bookshelf.reading` JSON 块仅作无 books 记录时的回退展示。**

依据：
- ReadingService.save_progress / restore_position 已只走 `books` 表（M2，结构化列 chapter_index/scroll_offset/scroll_ratio/chapter_pos/font_size/updated_at），M6 不改动这条写路径；
- bookshelf.json 的 reading 块在 M6 导入时原样保留进 `bookshelf.reading` 列，作为 Legado 别名/旧记录的兼容快照；
- 两条读取路径共存到 M7：新进度只写 books 表；bookshelf.reading 保留给书架 UI 展示与旧数据回退。M7 删除旧模型时以 books 表为准。

## 6. 与契约偏差（均为设计期授权内的实现细化）

1. **bookshelf / search_books 表增 `payload` 列**：契约 §2 列的是"关键列示意"（§6.3 明示"不写完整 DDL"）。为保证继承自旧 SourceService 的书架方法（换源/进度回写/目录缓存等）操作的 dict 字段无损往返，bookshelf 增 `payload` 列存整条记录；search_books 增 `payload/origin_order/saved_at` 列以对齐 SearchBookStore 运行语义。契约列出的投影列全部保留且已索引。
2. **appearance 并入策略**：`appearance.snapshot` 已存在时不覆盖（M5 运行期已写过更新偏好者优先），避免迁移回写旧值冲掉用户近期选择。
3. **M3 测试落点断言适配**：`test_sources_service_m3.py` #2/#6 原断言"保存/删除后 bookSource.json 文件内容"。介质切主库后该文件不再写，改为主库 `book_sources` 表查询；断言语义（保存后持久可见、删除后消失）完全保留，仅换介质。这是契约 §3"落点变、语义不变"的直接体现，与 §G 同步 lifecycle 版本断言同性质。
