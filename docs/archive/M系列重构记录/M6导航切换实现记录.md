## 2. 注册表设计（core 零 flet）

- 既有目的地常量与三个元组（`READING_DESTINATIONS` / `MANGA_DESTINATIONS` /
  `SOURCE_DESTINATIONS` / `TOOLS_DESTINATIONS`）**一字未动**——M2/M3/M5 测试按
  精确长度回查。
- 新增设置组：`DEST_SETTINGS_APPEARANCE = "settings.appearance"`、
  `DEST_SETTINGS_DASHBOARD = "settings.dashboard"`、`SETTINGS_DESTINATIONS`。
- 分组词汇表：~~`GROUP_READING / GROUP_SOURCE / GROUP_TOOLS / GROUP_SETTINGS`，
  `GROUP_ORDER = (阅读, 书源, 工具, 设置)` 为展示顺序~~。
  **2026-09-27 复核更正**：现为 3 组 `GROUP_SOURCE / GROUP_READING / GROUP_CONFIG`（书源/阅读/配置），
  `GROUP_ORDER = ('书源','阅读','配置')`（registry.py:128-138 实测），`GROUP_TOOLS`/`GROUP_SETTINGS`
  仅作向后兼容别名指向 `GROUP_CONFIG`。
- `NAV_META: dict[dest, (group, title)]` 是全量目的地权威清单（~~共 19 项：
  阅读 4 + 书源 5 + 工具 8 + 设置 2~~ **2026-09-27 复核实测 23 项：书源 5 / 阅读 5 / 配置 13**，
  且值扩为 `(group, title, hidden)` 三元组），纯字符串，core 不 import flet。
- `ViewRoute` 在 `factory` / `required_services` 基础上补 `title=""` / `group=""`
  （带默认值，向后兼容既有 `register(dest, factory, required_services=...)` 调用）。
- `register()` 新增关键字参数 `title` / `group`（可选）；各域 `register_destinations`
  不传，由 `attach_navigation_meta()` 统一贴元数据——装配期漏注册即报 KeyError，
  导航条不出现死项；重复 attach 幂等。
- `grouped_destinations()` 按 `GROUP_ORDER` 产出 `[(分组, [(dest, title), ...])]`，
  供导航容器渲染。

## 3. 导航容器（app/views/navigation.py）

- 宽窗（`page.width >= 720`，可注入 `width` 替身）：~~`NavigationRail(extended=True)` + 分隔条 + 内容区。Rail 目的地按组排列，每组前插一个 `disabled=True` 的分组头（纯展示，不可点）~~。
  **2026-09-27 复核更正**：Rail 现为**每分组一项**（图标 + 组名标签，navigation.py:282-287 实测，无 disabled 分组头）；组内非整页目的地合并为该页顶部的 `SectionView` 页签（`views/navigation.py:156`），整页目的地（hidden=True：阅读器/漫画/工具子页）不进 Rail。
- 窄窗（`width < 720`）：~~`ft.Column` = 内容区 + 底部 `ft.NavigationBar`（扁平目的地，不插分组头）~~。
  **复核更正**：底部 Bar 同样每分组一个入口（navigation.py:288-292 实测），与 Rail 同构。
- `NavigationHost.show(dest)`：`registry.get(dest)` 取路由 → 工厂重建内容区控件
  → 同步 Rail/Bar 选中态；未注册目的地抛 `KeyError`。
- 窗口跨阈值缩放：`page.on_resize` 时 `host.rebuild()` 换根布局，**内容视图保留
  不重建**；阅读器/漫画沉浸模式由各自视图内部处理（M2/M4 已交付），本容器不额外改造。
- 首屏默认落地 `reading.find_books`。

## 4. main.py 装配

```
_build_hub()                # 30 服务注册（status_report 含 hub 自身 = 31 行）

  ├─ views.reading.register_destinations   # M2/M4（含 manga）
  ├─ views.source.register_destinations     # M3
  ├─ views.tools.register_destinations      # M5

```
