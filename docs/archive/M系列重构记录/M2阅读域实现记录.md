## 1. ReadingService（reading_service.py）

- **落点**：阅读会话上下文、进度 save/restore、阅读器偏好、找书/换源编排。
- **迁入模型（零逻辑改动）**：自 `old_code/app/services/reading_progress.py` 原样迁入
  `ReadingPosition` / `ChapterViewport` / `ReadingSession`，仅删除依赖 bookshelf.json
  的 `ReadingProgressStore`（M2 进度改走 SQLite `books` 表）。`track/enter/bind` 等定位
  语义逐行保留。
- **进度持久化**：`save_progress(chapter_index, position)` 按 `books` 表结构化列
  upsert（chapter_index/scroll_offset/scroll_ratio/chapter_pos/font_size/source_url/
  book_url/name/author/cover_url/updated_at），发 `ProgressSavedEvent`；
  `restore_position(book)` 回表恢复，无记录返回 `None`。M2 **不读 bookshelf.json**。
- **偏好**：`save/get_reader_preference` 委托 SettingsService，键前缀 `reader.`（§3.9）。
- **编排**：`search_books` 组合 `SearchModel`（search_one 回调转发 RuleEngineService.search），
  完成发 `SearchFinishedEvent`（BookItem 转字典快照，事件不塞可变模型引用）；
  `switch_source` 复用 `merge_search_items` 排序；`apply_source_switch` 写回委托旧
  `SourceService.switch_bookshelf_source`（**组合而非继承，未改动 source_service.py**）。
- **书架/notShelf**：`open_book(shelve=...)` 经注入的旧 SourceService.add_to_bookshelf
  委托；`source_service` 为可选注入，缺失时阅读不中断。
- **偏差/裁决**：
  1. `open_book/load_chapters/load_content` 的 `source` 经服务内 `current_source` 持有
     （打开时记录），与契约 `load_chapters(book, force_refresh=False)` 签名一致。
  2. `switch_source` 在 M2 **不自动改写书架**，返回排序后候选列表，实际写回由
     `apply_source_switch` 在视图确认后调用——避免误切，待 M3 SourceService 外壳化后收敛。
  3. `stop_search` 仅占位（generation 语义由 SearchModel 新 search_id 切换实现，M2 无长驻句柄）。

## 2. BookmarkService（bookmark_service.py）

- **落点**：`add_bookmark/remove_bookmark/list_bookmarks`，落 `bookmarks` 表，增删发
  `BookmarkChangedEvent(op="add"/"remove")`。
- **存储**：`bookmarks(id PK/autoinc, book_url, chapter_index, offset, summary, created_at)`，
  对 `book_url` 建索引；内部 `threading.Lock` 串行化写。
- **偏差**：书签与自动续读进度是两条独立数据，不合并（§1.13）；删除无论是否删到都发事件，
  便于视图刷新。

## 3. ContentSearchService（content_search.py）

- **落点**：on_start 运行时 `CREATE VIRTUAL TABLE IF NOT EXISTS content_search USING fts5(
  book_url UNINDEXED, chapter_index UNINDEXED, offset UNINDEXED, text, tokenize='trigram')`，
  **不进版本化迁移**（契约 §9 末段）。
- **rebuild_index(book_url, source_url="")**：先清该书旧索引，遍历已缓存章节，仅对已缓存
  章节（reader-cache `load_content` 命中）的 text 块逐块写入，未缓存章节跳过。
- **search(book_url, keyword)**：≥3 字走 trigram MATCH（短语包裹防 FTS 语法错）；
  <3 字（常见中文双字词）FTS 无法命中，退化为 `text LIKE %kw%`。返回
  `{chapter_index, offset, snippet}`。
- **降级**：运行环境 sqlite 未编译 FTS5 时 `_fts_available=False`，search 返回空、不抛错。
- **偏差/裁决**：`rebuild_index` 额外接受可选 `source_url`（定位 reader-cache 书目录所必需，
  契约签名只给 book_url）；trigram 分词器与 <3 字 LIKE 回退为中文检索的必要实现选择。

## 4. BookCacheService（book_cache_service.py）

- **落点**：内层 `WholeBookCacheService` + `BookCacheService(Service)` 外壳。
- **逻辑零改动**：内层自 old_code 原样迁入，书内并发/断点续传/图片内联/`pin_book`
  钉住不淘汰全部保留；`cache_book(source, book, on_progress=None)` 签名不变。
- **外壳改动（仅外壳/参数来源/事件）**：
  - 实例参数 cache 根 / state_dir 改由 StorageService 提供（`paths.cache` / `paths.data`）。
    注意：`ReadingCache` 会在传入根下再追加 `reader-cache/`，故传入缓存根目录以保持
    磁盘布局 `<cache>/reader-cache/` 与旧行为一致。
  - 钉住集合 M2 在服务内 `self._pinned` 维护（`is_pinned`），M6 收敛 StorageService.pin。
  - `on_progress` 保留为服务内部钩子，对外进度事件统一走 DownloadService。
- **偏差**：`engine_factory` 缺省在 `cache_book` 内延迟构造默认 LegadoReadingEngine，
  便于测试注入假引擎；M3 切到 RuleEngineService 池后替换。

## 5. DownloadService（download_service.py）

- **落点**：`enqueue(kind, book_url, payload)->task_id` / `cancel(task_id)` /
  `list_tasks()->list[TaskInfo]`。
- **执行**：`kind=="whole_cache"` 时注册后经 `asyncio.ensure_future` 启动 BookCacheService
  执行；`on_progress` 钩子把 `BookCacheProgress` 折算为 task 进度并发 `DownloadProgressEvent`
  （服务层只发原始事件，0.5s 节流在 Controller）。
- **偏差/裁决**：
  1. 任务统计原契约写 `status.progress`；基类 Service 已有 `.status: ServiceStatus`
     且 `progress` 为 float 字段，故聚合统计改放独立属性 `task_report->{total,completed,running}`，
     避免与基类状态快照冲突。
  2. M2 任务仅内存注册表（`download_tasks` 表按 §6.3 草案随后续里程碑落库）。

## 6. ImageBookService（image_book_service.py）

- **落点（M2 只交付能力，视图 M4 接）**：
  - `chapter_images(book, chapter, source=None)`：经引擎 `content_document` 管线解析图片 URL，
    跳过已内联 `data:` 图。
  - `fetch_page_image(source, book, url, headers)`：走引擎 `fetch_media` 网络栈，返回 bytes。
  - `apply_color_filter(image, mode)`：Pillow `gray` 灰度 / `ink` 电子墨水二值化，跨平台。
- **偏差**：`chapter_images` 契约签名为 `(book, chapter)`，额外接受可选 `source`
  （缺省取 `current_source`），因为解析图片需要源上下文；M4 视图接时传入。

## 10. 与契约的主要偏差汇总

1. `ContentSearchService.rebuild_index` 增可选 `source_url`；FTS 用 trigram + <3 字 LIKE 回退。
2. `DownloadService` 任务统计属性命名为 `task_report`（避开基类 `.status.progress`）。
3. `ImageBookService.chapter_images` 增可选 `source`。
4. `switch_source` M2 不自动写回书架，改由 `apply_source_switch` 显式触发。
5. 钉住集合 M2 内存维护、下载任务 M2 内存注册（均按契约留给 M3/M6 收敛到 StorageService）。
