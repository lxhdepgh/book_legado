## 4. 与契约偏差（M3 累计，写入各线记录）

1. **CompatAuditService 反向依赖 SourceService 成环**：不进 dependencies，save_source/import_sources_json 的"保存即审"改 on_start 软解析 hub.require(CompatAuditService) + 构造注入替身，未就绪降级不阻断。
2. **SourceCheckService 取消方法命名 `cancel()`**（基类已有 async stop() 状态机，不覆盖）；生命周期停止走基类 stop()。
3. **RuleRepairService.repair 签名**为 `(source, chapter, *, extra_chapters, book, engine, timeout)`（底层 diagnose_content_rule 是 M2 冻结副本，签名不可改），非契约字面 repair(book_url)。
4. **events.py 三事件由导入视图线先按冻结签名落地**，检测线直接 import 未重复；SourceChangedEvent 同。
5. **test_reading_services.py 的 SCHEMA_VERSION 断言 `==2 → >=2`**（v3 向后兼容，跨线共享文件对账）。
6. **Flet 0.86.5 适配**：TextField 无 font_family、无 RichText，编辑器高亮改用 ft.Text(spans=...)。
7. **RuleRepairService.get_report 宽容调用**（契约未冻结签名），缺方法时退化为最小占位卡。
8. 检测 done/total 进度计数待服务侧进度事件细化，视图先逐源渲染。
9. 候选封面联网抓取未实现（留 RuleEngineService 通道，记录注明）。
