> 范围：仅视图/控制器层，**复用 M2 已交付 ImageBookService 服务能力，不新增/不改服务**。

## 2. 数据流与职责边界（契约 §7）

```
MangaReaderView ──回调──▶ MangaReaderController ──hub.get()──▶ ImageBookService
                                                          └──▶ ReadingService
   (ft 布局/渲染)              (取数编排/节流/事件)     chapter_images/fetch_page_image
                                                       open_book/save_progress(进度模型)
```

- 章节图片列表：`ImageBookService.chapter_images(source, chapter)`（复用 M2，跳过已内联 data: 图）。
- 单页字节：`ImageBookService.fetch_page_image(source, book, url)`（走引擎网络栈）。
- 色彩滤镜：**复用 M2 静态方法** `ImageBookService.apply_color_filter(pil_img, mode)`（Pillow gray/ink 预渲染，跨平台，无平台图像 API）。控制器取字节后在 `_prerender` 里打开 PIL → 滤镜 → 重编码 PNG → `view.set_page_bytes(i, png_bytes)`。
- 章节列表/进度：`ReadingService.open_book` 恢复 `session.position.chapter_index`，`save_progress` 落 books 表结构化列（§3.9）。

## 3. 关键设计点

- **纵向无限滚动**：`ft.Column(scroll=ft.ScrollMode.AUTO, on_scroll=...)`，三端一致（设计 §1.3）。
- **懒加载分块**：`CHUNK_SIZE=6`；`set_pages` 只渲首块，滚动距底 <400px 经 `on_request_chunk` 回调请 Controller 追加；Controller 层 `throttle(...,0.5)` 合并高频滚动（§7.4，不在服务层节流）。`has_more/rendered_count/total_count` 供控制器判定。
- **色彩滤镜**：原图模式下 `ft.Image(src=url)` 直接由 Flet 加载；切到灰度/电子墨水时，Controller 逐页 `fetch_page_image` 取字节 → Pillow 预渲染 → `ft.Image.src=<bytes>`（Flet 0.86 的 `Image` 接受 bytes，无 `src_base64` 属性）。换滤镜清空渲染通道内字节缓存重算。
- **缓存命中提示**：Controller 维护 `_page_cache: dict[url, bytes]`（渲染通道内字节缓存，同 URL 跨分块/重切滤镜复用），命中/未命中计数实时推 `view.set_cache_hint(hit,total)`。
- **进度位置记忆**：章节级——打开 image 书时 `open_book` 恢复 `chapter_index` 并开该章；滚动经 `on_save_scroll` → 0.5s 节流 → `ReadingService.save_progress(chapter_index, position)`。
- **事件**：订阅 `ReadingSessionChangedEvent`（换书/续读同步 `book_url`），detach 统一退订（attach/detach 对称）。

## 5. 与契约/设计的偏差（主动声明）

1. **缓存命中提示口径**：契约 §7 提"图片缓存命中提示"。M2 `fetch_page_image` 不返回磁盘缓存命中元数据，且本线约束"不改服务"。故提示的是**渲染通道内字节缓存**命中率（Controller 层 dict），非 BookCacheService 磁盘命中率。磁盘命中率待后续 `fetch_page_image` 扩展返回缓存标记后接入，不影响 M4 最小可用。
2. **进度粒度**：漫画长页内像素/比例位置未接 `ReadingSession.track`（那是文本流视口模型）；M4 落**章节级**进度记忆（chapter_index + 复用 session.position），页内滚动位置 M5 补。
3. **目录面板**：`on_open_directory` M4 暂接空操作（契约未要求漫画目录面板 M4 必做）。
4. **目的地分组**：设计 §7.2 把 MangaReaderView 列在 `library/` 包；按本任务交付要求落在 `views/reading/`，目的地键 `reading.manga`。

## 6. 跨平台冒烟清单（纯 Python 路径声明）

- 视图仅用 Flet 通用控件（Column/Image/IconButton/TextButton/Text），无 Windows 专属 API；
- 滤镜走 Pillow（`convert("L")` / `point` 二值化），三端一致，无平台图像 API；
- 网络取图经引擎既有网络栈（RuleEngineService），不直接调系统命令；
- 本线无新增第三方依赖（Pillow M2 已在 venv）。Win/macOS/Linux 同路径运行，无平台分支。
