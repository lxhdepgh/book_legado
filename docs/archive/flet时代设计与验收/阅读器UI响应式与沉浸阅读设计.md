# 阅读器 UI 响应式与沉浸阅读设计

## 1. 设计目标

在保持 Flet 技术栈和现有书源、书架、缓存、主题能力不变的前提下，使应用同时符合桌面与移动平台的常见阅读器操作习惯：内容优先、导航稳定、阅读不中断、设置即时反馈。

## 2. 设计原则

1. 阅读正文是最高优先级内容，进入正文后隐藏与当前阅读无关的全局导航。
2. 同一个动作在不同宽度下保持相同语义，只改变承载控件。
3. 临时操作使用浮层、抽屉或工具栏，不通过页面跳转破坏阅读位置。
4. 颜色只作为辅助表达，进度、缓存和错误状态必须同时具有图标或文字。
5. 设置修改应即时预览；取消时恢复，确认后持久化。
6. 鼠标、键盘和触摸均可完成核心阅读操作。

## 3. 响应式断点

| 宽度 | 模式 | 主导航 | 阅读目录 | 正文版心 |
| --- | --- | --- | --- | --- |
| `< 600px` | 紧凑 | 底部 NavigationBar | 底部弹层 | 两侧 16px |
| `600–899px` | 中等 | 紧凑 NavigationRail | 右侧抽屉 | 最大 680px |
| `>= 900px` | 宽屏 | 带标签 NavigationRail | 右侧抽屉 | 最大 760px |

页面必须使用 SafeArea 规避移动设备状态栏、圆角和底部手势区域。窗口尺寸变化后，只重建导航外壳，不重建业务视图，避免丢失搜索、目录和阅读进度。

## 4. 应用主导航

- 主入口保持“书源、阅读、配置”三项。
- 紧凑模式使用底部导航；中等和宽屏使用左侧导航。
- 宽屏侧栏显示图标和标签，中等模式只显示图标及悬浮提示。
- 阅读视图进入正文状态后隐藏主导航；退出正文后恢复。
- 主题预览离开配置页时仍执行取消预览逻辑。

## 5. 书架

### 5.1 继续阅读

书架顶部在存在阅读记录时显示“继续阅读”卡片，包含书名、当前章节、全书进度、缓存状态和继续阅读按钮。卡片只展示最近阅读的一本书，不与下方书架重复承担管理功能。

### 5.2 列表层级

- 第一层：书名。
- 第二层：作者、书源。
- 第三层：当前/最新章节。
- 辅助信息：阅读进度、未读数、离线状态。
- 换源、全书缓存、刷新、分组、移除收纳在更多菜单中。

## 6. 沉浸阅读

### 6.1 默认状态

- 正文居中，桌面最大宽度 760px。
- 顶部工具栏和全局导航默认隐藏。
- 底部只保留低干扰的章节名和全书进度；可在设置中关闭。

### 6.2 唤出操作

- 点击正文中央：显示/隐藏阅读工具栏。
- 点击或轻扫左侧：上一章。
- 点击或轻扫右侧：下一章。
- 工具栏包含返回、目录、章节进度、阅读设置和上一/下一章。
- 打开目录或设置时工具栏保持显示；关闭浮层后恢复用户此前状态。

### 6.3 桌面快捷键

| 快捷键 | 动作 |
| --- | --- |
| `Left` / `Right` | 上一章 / 下一章 |
| `PageUp` / `PageDown` | 上下滚动一屏 |
| `Space` | 向下滚动一屏 |
| `Esc` | 关闭浮层；无浮层时退出正文 |
| `Ctrl+F` | 打开目录并聚焦章节搜索 |
| `Ctrl+,` | 打开配置 |

输入框聚焦时不得拦截普通文本输入。

## 7. 目录面板

- 打开目录不离开正文，不改变滚动位置。
- 移动端使用底部弹层；中等及宽屏使用右侧面板。
- 显示书名、当前章节、章节数量、正倒序和搜索。
- 当前章节高亮并尽量滚动到可见区域。
- 选择章节后加载正文并自动关闭面板。

## 8. 阅读设置

第一阶段设置项：

- 字号：13–28。
- 行高：1.3–2.2。
- 段距：4–24px。
- 正文宽度：窄、标准、宽。
- 段首缩进：开/关。
- 对齐：左对齐/两端对齐。
- 阅读背景：跟随主题、纸张、护眼、夜间、墨水屏。
- 状态栏：显示/隐藏。

修改即时作用于当前正文，并保存到用户数据目录。主题切换不得覆盖独立的阅读排版设置。

## 9. 搜索与反馈

- 本地书架和目录搜索使用 200–300ms 防抖即时筛选。
- 网络找书由 Enter 或搜索按钮显式触发。
- 所有搜索框具备清除动作、空结果说明和键盘焦点状态。
- 长任务使用确定进度；无法计算时使用不确定进度，并保持取消入口。

## 10. 可访问性与主题

- 所有纯图标按钮提供 tooltip。
- 触摸目标不小于 44px。
- 进度和缓存状态包含文字或语义标签。
- 深色、浅色和 E-Ink 下均使用主题语义色，不写死正文前景色。
- 减少动画模式下禁用非必要页面与工具栏动画。

## 11. 验收标准

1. 在 430px、720px、1100px 三种宽度下导航形态正确且业务视图状态不丢失。
2. 进入正文后全局导航隐藏，退出后恢复；中央点击可切换工具栏。
3. 1100px 窗口正文行宽不超过 760px，430px 窗口无横向溢出。
4. 目录从正文内打开，选择章节后关闭且正文更新。
5. 阅读设置即时生效并在重启后恢复。
6. 键盘快捷键不会在搜索输入时误触发章节切换。
7. 继续阅读入口与书架记录一致，不产生重复书籍控件。
8. 浅色、深色和 E-Ink 主题下主要状态均可辨认。
9. 所有现有自动化测试通过，并新增响应式、沉浸阅读和设置持久化回归。

## 12. 实施结果

本轮设计已经落地：

- 主导航按 600px/900px 断点在底部导航、紧凑侧栏和展开侧栏间切换，并由 SafeArea 包裹。
- 进入正文后应用导航和阅读页标题区隐藏；正文工具栏默认隐藏，可由中央点击唤出。
- 左右点击、方向键用于章节切换；PageUp、PageDown、Space、Esc、F 和逗号键已接入。
- 正文默认最大宽度 760px，提供 620/700/760px 三档，支持字号、行高、段距、缩进、对齐、背景和底部状态栏设置。
- 阅读设置保存到用户数据目录 `reader-layout.json`，损坏或非法值自动降级到安全默认值。
- 目录在窄屏使用 BottomSheet，在宽屏使用右侧 AlertDialog；选择章节后关闭面板并留在正文。
- 配置页新增“阅读”标签，与正文内设置面板共享同一份持久化配置。
- 配置页新增“快捷键”说明，集中列出键盘、鼠标滚轮和触摸屏操作。
- 快捷键页支持自定义上一章、下一章、上下翻页、目录、配置及关闭/返回按键；配置持久化，重复绑定自动交换。
- Windows 鼠标滚轮和触摸纵向滑动均由正文可滚动 Column 原生处理。整篇正文不再使用动态构建 ListView，也不再手工转发滚轮事件。
- 阅读快捷键由 Page.on_keyboard_event 在应用层接收，仅在正文页面分发，避免局部 KeyboardListener 因焦点变化失效。
- 书架新增继续阅读卡片、全书进度条，并将未读及缓存状态改为主题语义色。
- 书架本地搜索增加 250ms 防抖，避免输入过程中频繁重建大列表。

自动化验收结果：`472 passed, 28 subtests passed`。
