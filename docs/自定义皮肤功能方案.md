# Legado 书源管理工具：自定义皮肤功能方案

版本：1.1  
日期：2026-08-11  
范围：Flet 桌面端、Android、iOS 及 Web 运行形态

## 1. 方案结论

参考 `base_history/legado-3.23.110211` 的实现，将“皮肤”拆成两个相互独立、可以组合的层级：

1. **应用皮肤**：控制书架、找书、书源管理、导入、检测、弹窗和导航的整体外观。
2. **阅读主题**：只控制正文阅读区域，包括背景、正文、标题、链接、图片衬底和亮度感受。

第一版不开放任意控件逐项改色，而采用“内置皮肤 + 强调色定制 + 阅读主题定制”。这样既满足个性化，也能保持对比度、危险色语义和跨平台一致性。

应用默认继续使用“跟随系统”，用户可选择浅色、深色、墨水屏或指定皮肤。设置必须即时预览、明确保存，并提供一键恢复默认。应用皮肤和阅读主题分别存储，但共享当前明暗/墨水屏模式，保持与 Legado 的使用习惯一致。

## 2. 设计依据

- Flet 支持分别配置 `page.theme` 和 `page.dark_theme`，也支持通过嵌套主题覆盖局部界面，因此可以用全局主题承载应用皮肤，用阅读区嵌套主题承载阅读主题。[Flet Theming](https://flet.dev/docs/cookbook/theming/)
- Flet `Theme` 已覆盖颜色方案、字体、卡片、导航、对话框、输入框、按钮、滚动条和状态提示等组件级主题，能够保持 Flet 技术栈而不引入自绘 UI。[Flet Theme API](https://flet.dev/docs/types/theme/)
- Fluent 2 建议使用“全局令牌 + 语义别名令牌”，把背景、文字、品牌和状态颜色按用途命名，避免直接在业务代码中硬编码颜色。[Fluent 2 Design Tokens](https://fluent2.microsoft.design/design-tokens)
- Fluent 将中性色、品牌色和状态色分开，并强调危险、警告、成功色只用于表达状态，不作为装饰色。[Fluent 2 Color](https://fluent2.microsoft.design/color)
- Apple 建议默认尊重系统明暗模式，避免简单反转颜色，并要求自定义颜色提供浅色和深色变体。[Apple Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode)
- 颜色不能成为唯一的信息表达方式；普通文本最低对比度应达到 4.5:1，较大或粗体文本最低为 3:1。[Apple Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility/)

### 2.1 Legado 源码主题基线

本方案以 `base_history/legado-3.23.110211` 为产品兼容基线，保留以下主题标准：

| Legado 标准 | 源码依据 | 本项目对应方案 |
|---|---|---|
| 应用主题与阅读配置分离 | `ThemeConfig.kt` 管理应用配色，`ReadBookConfig.kt` 管理阅读背景、文字和排版 | `ThemeService` 管理应用皮肤，`ReaderTheme` 独立管理阅读主题 |
| 日间、夜间、E-Ink 三套模式 | `ThemeConfig.getTheme()` 按 `isEInkMode`、`isNightTheme` 返回 EInk、Dark、Light | 外观模式增加“墨水屏”，优先级为 E-Ink > 深色 > 浅色；“跟随系统”只在浅/深间切换 |
| 日间与夜间应用配色分别保存 | `pref_config_theme.xml` 分别定义主色、强调色、背景色、底部导航背景和背景图片 | 每个应用皮肤必须同时提供 `light`、`dark` 变体，不用简单反色生成 |
| 应用主题使用有限语义色 | `ThemeConfig.Config` 使用 `primaryColor`、`accentColor`、`backgroundColor`、`bottomBackground` | 对外导入格式保留这四个基础角色，内部再展开为完整 Flet 语义令牌 |
| 阻止错误明暗背景 | `ThemeConfig.applyTheme()` 会把夜间亮背景、日间暗背景纠正为安全默认色 | 保存前检查背景亮度与文本对比度；不合格时自动修正并提示 |
| 阅读配置为日/夜/E-Ink 分别存值 | `ReadBookConfig.Config` 分别保存背景、正文色、状态栏图标和翻页参数 | 一个阅读主题包含 `light`、`dark`、`eink` 三个 variant，切换模式不覆盖用户另一模式配置 |
| 阅读背景支持纯色和图片 | `bgType`、`bgTypeNight`、`bgTypeEInk` 区分颜色、内置图片、外部图片 | MVP 先支持纯色；第二阶段支持本地图片，并限制尺寸、格式和读取目录 |
| 阅读主题可导入导出 | `ReadBookConfig.getExportConfig()` 和 `import()` 连同字体、背景资源处理 | 使用带版本号的 JSON/ZIP；导入先预览和校验，禁止执行代码和访问包外路径 |

这里的“兼容”指操作模型和配置能力保持一致，不照搬 Android 专属的状态栏、导航栏 API。Flet 各平台无法表达的字段应安全忽略，不能导致主题加载失败。

## 3. 当前项目现状

当前全局主题仅设置：

- `theme_mode = SYSTEM`
- Material 3
- `color_scheme_seed = BLUE`

各页面仍直接使用大量固定颜色，例如：

- `GREY_400 / GREY_600 / GREY_700`
- `BLUE_50 / BLUE_100`
- `RED_100 / RED_600`
- `GREEN / ORANGE`

这些固定颜色存在三个问题：

1. 切换深色模式后不一定具有正确对比度。
2. 用户更改品牌色时，选中态、徽标和提示色不会同步。
3. 页面之间无法共享统一的表面、正文、次要文字和状态语义。

因此，自定义皮肤不能只增加一个颜色选择器，必须先建立主题服务和语义令牌。

## 4. 用户功能设计

### 4.1 入口

在应用一级导航或更多菜单中新增“外观设置”。桌面端使用对话框或侧边面板，移动端使用全屏设置页。

设置页包含三个区块：

1. 外观模式
2. 应用皮肤
3. 阅读主题

### 4.2 外观模式

使用四段式选项：

- 跟随系统（默认）
- 浅色
- 深色
- 墨水屏

“跟随系统”是首次安装默认值。皮肤不得强制覆盖用户选择的外观模式，除非该皮肤被明确标记为“仅浅色”或“仅深色”。第一版内置皮肤应全部支持浅色和深色。墨水屏模式固定为白底、黑字、弱化阴影与动画、高对比边框，不受强调色皮肤影响；退出墨水屏后恢复此前模式。

### 4.3 应用皮肤

第一版提供以下内置皮肤：

| 皮肤 | 主色 | 视觉定位 | 默认用途 |
|---|---|---|---|
| 经典蓝 | `#3F51B5` | 稳定、中性 | 默认皮肤 |
| 翡翠绿 | `#2E7D6B` | 柔和、长时间使用 | 阅读与管理兼顾 |
| 暖琥珀 | `#9A6700` | 温暖、低刺激 | 夜间前的过渡环境 |
| 雅致紫 | `#6D5BD0` | 个性化、轻娱乐 | 漫画与小说用户 |
| 水墨灰 | `#4F5B62` | 低饱和、专业 | 桌面管理场景 |

每张皮肤卡展示浅色和深色两个缩略预览。选中后立即预览导航、卡片、按钮、输入框和状态标签，但用户点击“保存”前不写入持久配置。

### 4.4 自定义强调色

第一版允许用户从推荐色板或颜色选择器中调整“强调色”，但不允许直接修改危险、警告和成功色。

规则：

- 强调色用于主按钮、选中导航、焦点边框、链接和进度指示。
- 强调色不得直接作为大面积页面背景。
- 系统根据强调色生成浅色和深色 ColorScheme。
- 保存前执行对比度校验；不合格时自动调整前景色或拒绝保存。

### 4.5 阅读主题

阅读主题独立于应用皮肤，提供：

| 阅读主题 | 背景 | 正文 | 使用环境 |
|---|---|---|---|
| 跟随应用 | 使用当前应用表面 | 使用当前正文色 | 默认 |
| 纸张白 | `#FAF9F6` | `#242424` | 白天 |
| 羊皮纸 | `#F2E6C9` | `#3A3024` | 长时间小说阅读 |
| 护眼绿 | `#DDE8D5` | `#263228` | 低饱和阅读偏好 |
| 夜间黑 | `#121212` | `#D8D8D8` | 暗光环境 |
| 深海灰 | `#1B2028` | `#D5D9E0` | 夜间漫画/图文 |
| 墨水屏 | `#FFFFFF` | `#000000` | E-Ink 或高对比静态阅读 |

阅读设置继续保留字号，并新增：

- 行高：紧凑、标准、宽松
- 段间距：小、中、大
- 页面边距：窄、标准、宽
- 字体：系统默认、衬线、无衬线（仅显示已内置或平台可用字体）
- 图片背景：跟随阅读背景、黑色、白色、棋盘格

阅读主题切换应保持章节位置不变，不触发目录或正文重新请求。

### 4.6 预览与恢复

设置页顶部提供实时预览区，至少包含：

- 页面背景和卡片
- 主按钮与次按钮
- 输入框及焦点态
- 成功、警告、错误状态
- 正文标题、正文和链接

操作按钮：

- 取消：恢复进入设置前的主题
- 保存：持久化并应用
- 恢复默认：二次确认后恢复“跟随系统 + 经典蓝 + 阅读主题跟随应用”

## 5. 语义设计令牌

业务页面禁止再直接选择具体色阶。页面只引用以下语义角色：

### 5.1 表面与文字

- `surface_page`：页面底色
- `surface_card`：普通卡片
- `surface_elevated`：弹窗、菜单和浮层
- `surface_selected`：选中卡片或批量选择
- `text_primary`：标题和正文
- `text_secondary`：作者、来源、说明
- `text_disabled`：不可用状态
- `border_normal`：分隔线和普通边框
- `border_focus`：键盘焦点和当前输入

### 5.2 品牌与交互

- `accent_primary`
- `accent_on_primary`
- `accent_container`
- `accent_on_container`
- `link`
- `hover`
- `pressed`

### 5.3 状态

- `success / success_container`
- `warning / warning_container`
- `danger / danger_container`
- `info / info_container`

状态必须同时配合图标或文字，不允许只改变颜色。例如检测失败应同时显示错误图标和“失败”标签。

### 5.4 阅读专属

- `reader_background`
- `reader_text`
- `reader_heading`
- `reader_link`
- `reader_divider`
- `reader_image_background`
- `reader_selection`

## 6. 技术架构

### 6.1 新增模块

建议新增：

```text
app/
  models/
    appearance_settings.py
  services/
    theme_service.py
  themes/
    builtin_themes.py
    theme_tokens.py
  views/
    appearance_view.py
```

职责：

- `AppearanceSettings`：设置数据模型、默认值和迁移。
- `ThemeService`：加载、校验、保存、生成 Flet Theme、通知界面更新。
- `ThemeTokens`：语义令牌及浅色/深色值。
- `builtin_themes`：内置皮肤定义。
- `AppearanceView`：设置、预览和恢复默认 UI。

### 6.2 持久化格式

保存到用户数据目录，不写入 `resource`：

```json
{
  "version": 2,
  "mode": "system",
  "previous_mode": "system",
  "skin_id": "classic_blue",
  "custom_accent": null,
  "reader": {
    "theme_id": "follow_app",
    "variants": {
      "light": {"background": "#FAF9F6", "text": "#242424"},
      "dark": {"background": "#121212", "text": "#D8D8D8"},
      "eink": {"background": "#FFFFFF", "text": "#000000"}
    },
    "font_family": "system",
    "line_height": "standard",
    "paragraph_spacing": "medium",
    "page_margin": "standard",
    "image_background": "follow_reader"
  }
}
```

文件建议为：

```text
%LOCALAPPDATA%/LegadoBookSourceCheck/appearance.json
```

其他平台继续使用 `SourceService.data_dir` 对应目录。

保存采用临时文件替换，配置损坏时回退默认值并保留损坏文件供诊断。

### 6.3 Flet 映射

应用皮肤映射到：

- `page.theme`
- `page.dark_theme`
- `page.theme_mode`
- `Theme.color_scheme_seed` 或完整 `ColorScheme`
- `Theme.card_theme`
- `Theme.navigation_bar_theme`
- `Theme.dialog_theme`
- `Theme.input`、按钮、列表、滚动条和 SnackBar 相关子主题

阅读主题使用包裹正文区域的嵌套 `Container(theme=..., theme_mode=...)`，并把正文背景与文字色从固定值改为阅读令牌。运行时先解析当前模式，再选择阅读主题对应的 `light`、`dark` 或 `eink` variant；这对应 Legado `curTextColor()`、`curBgStr()` 的取值方式。

### 6.4 更新机制

主题变更流程：

```text
设置页临时选择
  → ThemeService 生成预览主题
  → Page/阅读容器即时更新
  → 用户保存
  → appearance.json 原子写入
  → 发布 appearance_changed
  → 各视图刷新依赖令牌的局部控件
```

不建议重建 `BookSourceApp` 或重新加载书源；主题切换不能中断搜索、检测、阅读和切换书源任务。

## 7. 现有代码改造范围

### P0：主题基础设施

1. 新增设置模型和 ThemeService。
2. 从持久化配置生成 `theme`、`dark_theme` 和 `theme_mode`。
3. 将全局 `BLUE` 种子迁移到 ThemeService。
4. 建立主题变更通知与恢复默认。

### P1：语义色收口

优先替换：

- 书架未读徽标的 `BLUE_100`
- 管理页选中卡片的 `BLUE_50`
- 所有 `GREY_400/600/700`
- 错误文本和危险操作的 `RED_*`
- 检测结果的 `GREEN/ORANGE`
- 全局成功/错误 SnackBar 背景

危险操作仍使用 danger 令牌，不随用户强调色改变。

### P1：外观设置页

实现外观模式、内置皮肤、强调色、预览、保存、取消和恢复默认。

### P2：阅读主题

把阅读背景、正文、标题、链接和图片衬底放入独立主题；补充行高、段间距、边距和字体选项。

### P2：导入导出

允许导出单个自定义皮肤 JSON，并在导入时校验版本、字段、颜色格式和对比度。第一版不支持执行脚本、远程字体或网络背景图，避免安全和版权风险。

## 8. 安全与兼容约束

- 皮肤文件只能包含声明式 JSON，不能包含 Python、JavaScript 或动态表达式。
- 禁止皮肤改变危险操作语义，例如把删除按钮渲染为成功绿色。
- 不允许皮肤隐藏焦点框、禁用状态、滚动条或进度指示。
- 不下载远程字体和图片；自定义字体仅使用应用内置字体。
- 未知字段忽略，未来版本通过 `version` 迁移。
- 配置读取失败不得阻止应用启动。
- 移动端系统状态栏、导航栏应与当前明暗模式匹配。

## 9. 验收标准

### 功能

- 首次启动默认为跟随系统和经典蓝。
- 浅色、深色、系统模式切换立即生效。
- 5 套内置皮肤在浅色和深色下均可用。
- 应用皮肤与阅读主题可以独立组合。
- 取消预览恢复原设置；保存后重启仍保持。
- 恢复默认不会影响书源、书架、缓存和阅读进度。

### 可访问性

- 普通文本对比度不低于 4.5:1。
- 大号或粗体文本不低于 3:1。
- 焦点态无需依赖颜色即可识别。
- 成功、警告、错误均同时使用图标/文字。
- 深色模式下弹窗比基础页面具有可感知的表面层级。

### 稳定性

- 主题切换不重建阅读引擎，不取消正在运行的任务。
- 配置损坏时自动回退默认皮肤。
- Windows、macOS、Linux、Android、iOS 的外观模式行为一致。
- 现有功能与全项目测试保持通过。

## 10. 建议实施顺序

| 阶段 | 内容 | 预计风险 |
|---|---|---|
| 第 1 阶段 | ThemeService、设置模型、5 套皮肤、系统明暗模式 | 低 |
| 第 2 阶段 | 清理固定颜色、设置页和实时预览 | 中 |
| 第 3 阶段 | 阅读主题、字体和排版参数 | 中 |
| 第 4 阶段 | 皮肤导入导出、自动对比度审计 | 中高 |

建议先交付第 1、2 阶段作为皮肤功能 MVP；阅读主题在其上独立迭代。MVP 不包含背景图片、动态动画皮肤、在线皮肤市场和第三方代码扩展。
