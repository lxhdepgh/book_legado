## 4. 与契约偏差（M5 累计，写入各线记录）

1. WebDavService.restore(url, token)：url=远端包路径，token 为一次性口令覆盖位（凭据统一走 SettingsService.webdav.*）；设置导出为白名单子集（剔除凭据）。
2. ReplaceRuleService：replace_rules 增 is_regex/时间戳列（对齐 Legado isRegex）；dict_rules 增 rules_json 列；download_tasks 表由本线在 v5 一并建好。
3. QrCodeService 不硬依赖 SourceService/ReplaceRuleService（JSON 互操作在视图层，避免工具域反向依赖书源域）。
4. BrowserService 拓扑 dependencies=()（协作者 on_start hub.require）；SUSPENDED 以 listening=False/bound_port=0 可观测体现。
5. BrowserInteractionCallback 采用结构化实现（避免元类冲突）。
6. ThemeService 的 SettingsService 软依赖；appearance.json 旧值迁移留 M6（本线仅停止写入）。
7. opencv 5.x 中等分辨率偶发漏检定位符 → decode_image 加"放大 2x 最近邻重试"兜底。
