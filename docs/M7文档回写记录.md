## 2. current-system-design.md 回写要点

- 文首明确标注：**本文档描述重构完成后的当前系统设计，旧单体 views/services 已删除**。
- 总体架构改为进程内多服务：`main.py`（_build_hub 装配）→ `ServiceHub.start_all()` →
  `build_app_shell` / `NavigationHost`；分层 `views → controllers → services → core → storage`。
- `app/core/` 九模块逐一落职责：lifecycle / hub / bus / events / engine_worker /
  storage / settings / registry / interfaces。
- 26 业务服务按域分包成表：sources 5 / reading 7（含 engine 外壳）/ content 4 /
  tools 10；每个服务的职责以 main.py 注册顺序与代码实际命名为准（含 RssService /
  LocalBookService / ReadAloudService / MediaPlayService 四个 M4 服务）。
- 存储写为三类介质：SQLite 主库 `legado.db`（schema v6，表清单按
  `app/storage/schema.py` v1–v6 逐版本列出：settings/cookies/books/bookmarks/audit_log/
  tts_profiles/rss_sources/rss_articles/replace_rules/dict_rules/fonts/download_tasks/
  book_sources/bookshelf/search_books + 运行时 FTS5 content_search）、文件目录
  （reader-cache/image-cache/downloads/chromium-profile*）、互操作 JSON（仅导入导出）。
- UI 层写 `NavigationHost`（四组 19 目的地、720px 宽窄窗切换、ViewRegistry 声明式路由、
  detach 防泄漏）与 `ServiceDashboard`（状态/启停控制/50 条事件环形缓冲）。
- 保留有价值历史段落并落成"旧单体 → 新架构映射表"：规则三层结构、Legado 兼容层守门
  （test_legado_compat 486 条）、SearchModel 找书/换源/notShelf 语义、浏览器分级三档。

## 4. PyInstaller 打包准备结果

- **环境**：conda 环境 `legodo_booksource_check`（Python 3.12.13）已装 **PyInstaller
  6.21.0**，无需 pip install；全部关键三方库可 import。
- **hidden-import 逐一定论**（按全仓 import 扫描，非拍脑袋）：
  - 必需且静态分析易漏的懒加载包：`feedparser`、`ebooklib`(+lxml)、`fitz`(pymupdf)、
    `pyttsx3`、`edge_tts`、`qrcode`、`cv2`、`py7zr`、`rarfile`、`html5lib`、
    `jsonpath_ng.ext`、`playwright.async_api`；
  - 框架/核心：flet 三件套、aiohttp/aiohttp_socks、quickjs、elementpath、bs4、PIL、
    Crypto、opencc、fontTools、charset_normalizer、regex。
  - **评估排除**：`requests`、`websockets`——全仓 app/ 零 import，不列入。
- **--add-data**：`app/resources/publicsuffixes.gz` 必须落到包内 `app/resources/`
  （`public_suffix._DATA` 按 `Path(__file__).parents[2]/resources` 定位，冒烟断言在位）；
  `resource/` 为可选（当前代码不消费，json 是 gitignore 用户语料）。
- 产出：`docs/M7打包说明.md` 含构建命令、`LegadoReader.spec` 草案、打包后验证清单、
