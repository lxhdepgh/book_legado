## 3. --add-data 评估

| 数据 | 包内落点 | 必要性 |
| --- | --- | --- |
| `app/resources/publicsuffixes.gz` | `<MEIPASS>/app/resources/publicsuffixes.gz` | **必需**。`app/services/engine/public_suffix.py` 用 `Path(__file__).resolve().parents[2] / "resources" / "publicsuffixes.gz"` 定位；冻结包内 `__file__` = `_MEIPASS/app/services/engine/public_suffix.py`，故 parents[2] = `_MEIPASS/app`。smoke_test 直接 `assert _DATA.is_file()`，落点错则冒烟挂 |
| `resource/` | `<MEIPASS>/resource/` | 可选。`main.py` 里 `resource_dir = _ROOT/"resource"` 当前注释"不消费，保留通道"；其中 `resource/*.json` 是 gitignore 的用户语料，不建议随包分发 |

add-data 分隔符：Windows 用 `;`，macOS/Linux 用 `:`。

## 5. spec 草案（`LegadoReader.spec`，放项目根）

```python
# -*- mode: python ; coding: utf-8 -*-
# M7 PyInstaller spec 草案（Agent B 线准备）。实际回归由集成方在 Agent A 删除冻结文件后跑。
from PyInstaller.utils.hooks import collect_submodules

block_cipher = None

hiddenimports = [
    # UI / 框架
    "flet", "flet_audio", "flet_video", "flet_webview",
    # 网络
    "aiohttp", "aiohttp_socks",
    # 规则兼容层
    "quickjs", "elementpath", "jsonpath_ng.ext", "bs4", "html5lib",
    "PIL", "Crypto", "opencc", "fontTools", "charset_normalizer", "regex",
    # 浏览器
    "playwright.async_api",
    # 服务懒加载
    "feedparser", "ebooklib", "lxml", "fitz",
    "pyttsx3", "edge_tts", "qrcode", "cv2",
    # 老板键托盘（§2 表：win_tray 懒 import，静态分析扫不到）。这三条只在 Windows 上有意义；
    # 非 Windows 上 win_tray._load_backend() 本来就返回 None，功能自己降级，不需要额外分支。
    "win32gui", "win32con", "win32api",
    "py7zr", "rarfile",
]
# bs4 / 动态 loader 子包兜底（按需保留）
hiddenimports += collect_submodules("ebooklib")

a = Analysis(
    ["main.py"],
    pathex=["."],
    binaries=[],
    datas=[
        # 落点必须是 app/resources/（public_suffix._DATA 按 __file__ 相对定位）
        ("app/resources/publicsuffixes.gz", "app/resources"),
    ],
    hiddenimports=hiddenimports,
    hookspath=[],
    hooksconfig={},
    runtime_hooks=[],
    excludes=["tests", "base_history", "other_history", "old_code"],
    cipher=block_cipher,
)
pyz = PYZ(a.pure, a.zipped_data, cipher=block_cipher)

exe = EXE(
    pyz, a.scripts, a.binaries, a.zipfiles, a.datas, [],
    name="LegadoReader",
    debug=False,
    bootloader_ignore_signals=False,
    strip=False,
    upx=False,               # 杀软误报与解压性能权衡，默认不开
    console=False,           # windowed 应用；排障时改 True 看日志
    target_arch=None,
)
```

跨平台提示：同一 spec 在 macOS/Linux 上 `datas` 元组写法不变（PyInstaller 内部处理），
但 `--add-data` 命令行分隔符需换成 `:`；`pyttsx3` 的 comtypes/pywin32 仅 Windows 有意义，
其他平台构建时可从 hiddenimports 剔除（运行期有降级）。

### 8.3 排障链（DLL load failed while importing pyexpat）

| 轮 | 假设 | 措施 | 结果 |
| --- | --- | --- | --- |
| 1 | pyexpat 未收集 | hidden-import `pyexpat` | 仍失败 |
| 2 | VC runtime 缺失 | binaries 补 vcruntime140.dll | 仍失败 |
| 3 | VC 不全 | binaries 补 vcruntime140/140_1/threads + msvcp140 全套 | 仍失败 |
| 4 | UCRT API-set 存根缺失（系统 System32 无 api-ms-win-crt-*） | binaries 补 ucrtbase.dll + 15 个 api-ms-win-crt-* | 仍失败 |
| 5 | 单文件解压环境 | 转 onedir | 仍失败 |
| 6 | **版本错配（根因）** | pefile 证明 pyexpat.pyd 按**序号**从 libexpat.dll 导入；哈希比对发现 PyInstaller 误收 **conda 根 `D:\env_manger\minicaoda\Library\bin\libexpat.dll`（expat 2.7.1 旧版）**，而 pyexpat.pyd 同源的是 env 的 **expat 2.8.2** → binaries 钉住 `envs\legodo_booksource_check\Library\bin\libexpat.dll` | **冒烟 exit 0** |

> 前 5 轮失败均为第 6 轮根因的表现：序号导入在旧版 libexpat 上解析失败（错误 182/216），
> 与 VC runtime / UCRT / 单文件形态无关。conda 根多个 env 并存（expat 2.7.1–2.8.4 共 8 版），
> PyInstaller 按搜索路径取到根环境的旧版是误收集主因。

### 8.4 spec 最终要点（与 §5 草案的差异）

- **onedir**：EXE 仅 `pyz, a.scripts` + `exclude_binaries=True`，新增 `coll = COLLECT(exe, a.binaries, a.zipfiles, a.datas, name="LegadoReader")`。

- **console=False**（windowed 桌面形态）。
- `pyexpat` 保留在 hiddenimports。
- 包体约 500MB 量级（onedir 目录含 numpy/cv2/playwright 等原生库，未压缩）。
