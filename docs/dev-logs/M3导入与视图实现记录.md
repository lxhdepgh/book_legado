## 3. 关键设计决策

### 3.1 并行健壮性：懒解析兄弟服务类
SourceService / SourceCheckService / RuleRepairService / CompatAuditService 由并行线实现、
本线开工时尚未落盘。各控制器与 OnlineImportService 对它们的类引用一律 **try/except 懒解析**
（缺失时退化为同文件占位类），兄弟服务落盘后自动切真类，本线代码零改动：

```python
try:
    from app.services.sources.source_service import SourceService
except Exception:
    class SourceService: pass   # 并行期占位，测试替身覆盖
```

OnlineImportService 的 `dependencies` 元组同样按 dotted path 懒解析，缺依赖降级为空，
不阻断本服务导入。测试用构造注入替身（source_service=/audit_service=/http_fetcher=），
**不真联网**。

### 3.2 OnlineImportService 路由（契约 §7）
- `import_from_url(url, kind, headers=None)`：aiohttp 拉取（默认器，懒 import aiohttp）→ 分发；
- `import_from_file(text, kind)`：本地文本；
- **即时路由**：book_source / txt_rules → `SourceService.import_sources_json(text) -> (count, errors)`；
- **懒路由占位**：rss → 待 M4 RssService；replace_rules / dict_rules / theme → 待 M5；
  tts → 待 M4；占位时 count=0、warnings 含"待 Mx 就绪"，ImportFinishedEvent 照发；
- 书源导入前逐条 `CompatAuditService.audit_source`，缺口汇总 warning **不阻断**；
- 完成发 `ImportFinishedEvent(kind, count, errors)`（errors 含 warning 汇总）。
- 纯 Python、零 flet；不含任何规则落库逻辑（落库一律委托 SourceService）。

### 3.3 视图边界（§7.5）
五视图均为轻壳：`ft.Column` 子类，只渲染 dict 快照 + 发回调槽；零 `app.services.*` import
（AST 守门测试）。数据经各自 Controller，Controller 经 `hub.get()` 取服务，
协程经 `engine_call` 派 EngineHub。跨视图导航（列表→编辑器/导入/检测）经装配处注入回调，
视图间零互引。

### 3.4 代码编辑器（§1.6）
纯 Flet 自绘：`TextField` 输入 + `ft.Text(spans=)` 分词高亮层（Flet 0.86 无 RichText，
用 Text+spans）。词表 `RULE_HIGHLIGHT_KEYWORDS` 取自 legado_rule_parser 方言关键字
（@取值后缀 / @前缀分析器 / XPath 函数），纯函数 `tokenize_rule` 可离线单测。
保存路径：解析 JSON → `SourceService.save_source` → `CompatAuditService.audit_source` 提示渲染。

## 4. 与契约的偏差（需集成方知悉）

1. **M3 四事件由本线先落 `app/core/events.py`**：契约 §2 的 SourceChanged / CheckFinished /
   RepairReportReady / ImportFinished 在本线开工时 events.py 尚未含；本线按契约冻结签名补齐。
   若并行线（Agent A/B）也追加同名类，集成时以本文件签名为准合并（字段顺序一致）。
2. **编辑器 Controller 不订阅事件**：保存即校验是动作驱动；刻意不订阅 SourceChangedEvent，
   避免外部变更在用户编辑中途重置编辑器文本。测试据此只校验"attach/detach 不泄漏"。
3. **RuleRepairService.get_report 为宽容调用**：契约 §5 只冻结 `repair()/apply_fix()`，
   事件仅带 report_id。Controller 取回报告时 `getattr(service, "get_report", None)` 容错，
   缺该方法时退化为 {report_id, source_id} 最小占位卡；并行线补 get_report 后自动增强。
4. **检测进度计数未接**：CheckFinishedEvent 为每源一条，done/total 计数需服务侧配合；
   M3 视图先渲染逐源行 + 完成态文案，进度条留待 SourceCheckService 进度事件细化。
5. Flet 0.86.5 适配：TextField 无 `font_family`、无 `ft.RichText`，高亮改用
   `ft.Text(spans=[ft.TextSpan(style=ft.TextStyle(color=...))])`。
