### 1. 控制器与服务的断链接通（找书/书架空数据）

重构把视图拆成 `app/views/**` + `app/controllers/**` 后，多个控制器构造时拿到了服务却没用上，
页面渲染空列表、按钮点了没反应。补齐的契约：

- 视图 `attach()` 时控制器排队的任务，切页后可能才跑 → 每个 `await` 之后统一
  `if self._view is None: return` 守卫（`find_books_controller` 的
  `_load_sources` / `_load_categories` / `_open_category` / `_load_more_browse` / `_do_shelve`，
  `bookshelf_controller` 的 `_load` / `_remove_and_refresh` / `_do_switch`）。
  事件回调（`_on_*`）不需要该守卫：`detach()` 已退订。
- 事件回调（`SourceChangedEvent` 等）跨线程回界面循环，走 `BaseController.ui_call` 编组。
- 事件驱动的静默刷新不再覆盖用户刚看到的操作结果：`_load_sources(report=False)`、
  `_load(report=False)`，只有主动刷新/首次装配才写状态行。

### 8. 服务页：从整页灰砖到 31 行状态表（用户点名）

现象：「配置 → 服务」页只剩一块灰底，什么都读不出来。用户同时问「现在是否已经拆分
成多个服务了」——**是**：启动后注册 31 行（`ServiceHub` 总控 1 + 基础设施 4 + 业务 26，
业务按域为 规则引擎 1 / 阅读 6 / 书源 5 / 内容形态 4 / 工具 10），但页面上看不见。

两个叠加的根因（`app/views/service_dashboard.py` 整页重写时都记进了模块 docstring）：

1. **目的地形态违规**：`build_dashboard()` 返回的是 `ft.View(route="/dashboard")`，
   而 M6 之后目的地由 `SectionView` 塞进 `ft.Container` 的页签里。`View` 是页面级路由
   容器，嵌在控件树里 Flutter 直接不渲染——这就是那块灰砖。现在与 `AppearanceView`
   等其余目的地同构（`DashboardView(ft.Column, expand=True, scroll=AUTO)`）。
2. **改控件的循环错了**：`DashboardController` 早期自己 `bus.subscribe`，EventBus 把
   async 处理器投递到 **EngineHub 守护 loop**，处理器在那边直接写控件并 `page.update()`
   ——跨线程且没人 flush，服务状态变了界面也不动。现在继承 `BaseController`，
   `subscribe` 统一编组回界面循环并在收尾 flush。

补齐的展示能力：

- 状态列中文化（运行中 / 已挂起 / 停止中 / 初始化…，未知值原样透出），新增「所属域」列
  （按服务类 `__module__` 前缀归类，不 import 任何服务实现）；表头加汇总行
  「共 N 个服务 · 运行 X [· 已挂起 Y][· 降级 Z][· 已停 W]」。
- 每行进度改成 `ProgressBar`：`status.progress` 为 `None` 时走不定长、有值时确定值。
  旧版此处是 `-` 文本，RUNNING 的服务看着像没反应的灰块。
- **降级可见**：`status_report()` 里 RUNNING 却带 `last_error`（必需协作者缺失）的行，
  状态格转橙，与真正的 SUSPENDED 区分。
- 列宽不固定，整表包进 `ft.Row(scroll=AUTO)` 横向滚动，最后一列「操作」不再被裁掉。
- **2s 心跳**（`AUTO_REFRESH_SECONDS`）：进度由 RSS / 下载 / 检测就地写
  `status.progress`，从不发事件，只订阅事件收不到；心跳重读快照并按签名（行 id + 状态 +
  进度 + 错误）比较，没变就不重建表格。`on_detach` 取消心跳任务。

测试：`tests/test_service_dashboard_m6.py` 13 → **24 项**，改用真实 `DashboardView`
（把控件表面一起跑上）。新增断言含 `assertIsInstance(view, ft.Column)` +
`assertNotIsInstance(view, ft.View)`（就是这条能钉住灰底回归）、中文状态列、域归类表、
降级着色、按钮禁用矩阵、心跳只在下发时重绘、detach 后心跳取消且晚到事件不再进面板。
